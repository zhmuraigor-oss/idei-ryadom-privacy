Конфиденциальность

Приложение «Идеи рядом» работает офлайн. Оно не требует учётной записи, не использует рекламу или аналитику и не отправляет сведения о пользователе разработчику.

Данные на устройстве

Избранные идеи, имена, даты, заметки и статусы планов сохраняются в локальном хранилище приложения на вашем устройстве. Их можно удалить, очистив данные приложения или удалив его. При удалении приложения планы и заметки могут быть потеряны.

Резервная копия

По вашему действию приложение создаёт файл с избранным, планами, именами, заметками и отметками выполнения. Файл сохраняется в выбранном вами месте. Приложение не отправляет его разработчику. При передаче файла другим людям им станет доступно его содержимое.

Системное резервирование Android

В Android разрешено системное резервирование данных приложения. Если оно включено в настройках устройства, Android может создавать копию в вашей учётной записи или переносить данные между устройствами. Этим управляет операционная система; разработчик не получает доступ к такой копии. Наличие и полноту системного восстановления приложение не гарантирует: перед важными изменениями сохраните собственный файл копии.

Передача идей

Кнопка «Поделиться» открывает стандартное меню устройства. Передача выбранной идеи происходит только после вашего действия и зависит от выбранного вами приложения.
